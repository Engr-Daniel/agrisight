## One additional finding already grounded in prior validation

E1's actual aggregate reports11268 main-season plot records with irrigation infrastructure and262619 without it, with zero missing/other responses. Thus **11268 /273887 =4.11%** of valid released main-season plot records report infrastructure. This denominator includes cultivated plots, temporarily fallow conventional plots and kitchen gardens, not143105 households. This is a derived display percentage from previously SQL/Python-reconciled counts, not a new field-level data run.

Supported interpretation: infrastructure is reported on a small share of this plot roster, making infrastructure verification and reported methods/sources useful follow-up questions. Unsupported interpretations include “95.89% of farmers need irrigation,” “all remaining plots are rain-fed,” or a recommendation to fund particular states. Crop-level actual irrigation use is a separate candidate field, `s03_q05`; comparing it with infrastructure requires a validated join and explicit treatment of plots with multiple crops.

## Questions not established by this release review

No variable label containing credit, loan, extension or insurance was found in the21-module label scan. That is not proof that the original survey never asked about these topics; it means this review has not identified a usable released measure. Do not present credit exclusion, extension coverage, insurance gaps or unmet demand as findings from these data. A machinery reference in a loss-reason option is not an equipment-access variable. GHS remains an alternative only if a specifically selected service-access question warrants a separate source review.

Yield/profitability, current conditions, trends, causal programme impact, geographic agricultural prevalence and cross-season comparisons remain outside the verified scope. Measurement lineage, units, denominators, prices/costs, reference periods or design information are insufficiently established for those claims. The current state map remains sample coverage only.

## Implementation order and definition of done

Start with irrigation infrastructure/method/source, then crop portfolio/diversity, then seed-source patterns. This moves from already reviewed plot fields to richer, stakeholder-relevant modules while controlling joins and denominator mistakes. Tenure/travel can follow as a small plot-context increment. Harvest difficulties and sales/storage deserve a separate branch/skip/period review before charts.

For each increment: specify the stakeholder question, grain, allowed values, reference period, inclusion/exclusion rules, denominator and supported interpretation **before** calculating a result; inspect actual missingness/skip patterns and key relationships; independently reconcile Python/SQL aggregates; test manually counted positive/negative/edge fixtures; reproduce a packaged run; review disclosure and pin a new aggregate manifest; then add the chart with its interpretation, source and limitations. Preserve existing artifacts and never silently broaden their contracts. Missing or unsupported findings remain unavailable.

Acceptance for this review is an evidence-backed shortlist and explicit next increment, not completion of these eight analyses. No new statistical findings beyond the clearly identified prior-count calculation are claimed.
